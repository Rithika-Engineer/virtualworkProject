# Quick Note Application

A simple full stack Quick Note Application built using HTML, CSS, JavaScript, Flask, and SQLite.

## Features
- Add Notes
- Edit Notes
- Delete Notes
- Search Notes
- Store Notes in Database

## Technologies Used
- HTML
- CSS
- JavaScript
- Flask
- SQLite

## Project Structure

quick-note-app/
│
├── backend/
│   ├── app.py
│   ├── database.db
│
├── frontend/
│   ├── index.html
│   ├── style.css
│   ├── script.js
│
└── README.md

## How to Run

### Backend

Open terminal inside backend folder:

python app.py

### Frontend

Open terminal inside frontend folder:

python -m http.server 5500 --bind 127.0.0.1

Open browser:

http://127.0.0.1:5500/
